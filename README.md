# GraphicsGale - QA Pet Project

## Goal:
- Testing the GraphicsGale application to practice manual QA and produce structured test artifacts (reports, bug logs, documentation reviews).

## Testing Types:
- Exploratory Testing (Black-Box Method);
- Functional Testing (verification of core features);
- UI Testing (interface behavior and usability);
- Documentation Testing (verification of consistency between documentation and application).

## Tools:
- GraphicsGale;
- GitHub;
- Markdown.

## Scope
Desktop application testing (non-web, Windows environment).

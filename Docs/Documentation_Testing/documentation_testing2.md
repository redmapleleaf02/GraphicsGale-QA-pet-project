# Documentation Testing - Session 2

## Goal:
- Verification of chapter "3. Tutorial" against the actual behavior of the application.

## Notes and observations:

### 1. Chapter "3. Tutorial":

### 1-1. Section "3-2. Paint":
- Section "3-2. Paint" contains the following text: "If the editing area of the canvas is too small for painting, use Magnifier. Click the canvas to zoom in an image around the cursor, and right-click to zoom out";
- In the application, the tool is named "Zoom", while in the documentation it is referred to as "Magnifier";
- In chapter "5. Paint Tools", the tool is listed as "Magnifier" with the description "Click the image to increase or decrease the magnification factor".

Impact:
- Inconsistency in tool naming.

Evidences:
- Screenshots are located in the directory "Bugs/Documentation Testing Session2";
- Screenshot names: "documentation_testing_session2_bug1.png", "documentation_testing_session2_bug2.png", "documentation_testing_session2_bug3.png".

Severity: low.
Priority: minor.

Improvement suggestions:
- Option 1: Rename the tool in the application from "Zoom" to "Magnifier";
- Option 2: Rename the tool in the documentation from "Magnifier" to "Zoom".

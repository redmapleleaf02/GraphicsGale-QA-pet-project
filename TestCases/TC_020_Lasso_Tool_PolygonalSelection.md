# GraphicsGale - Test Case 20

## ID: TC020
## Title: Using the "Lasso" tool. Selecting an area by polygon

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Lasso" tool;
2. Left-click without dragging and keep left-clicking to create a polygon;
3. Right-click the last point to close the polygon.

### Expected Result:
- The tool creates a polygonal selection area.

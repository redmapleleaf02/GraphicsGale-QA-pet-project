# GraphicsGale - Test Case 30

## ID: TC030
## Title: Using the "Connect Line" tool

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Connect Line" tool;
2. Left-click and drag to draw a line.

### Expected Result:
- The tool draws a line on the canvas.

# GraphicsGale - Test Case 34

## ID: TC034
## Title: Using the "Connect Line" tool. Drawing a stair-step (diagonal) line

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Connect Line" tool;
2. Left-click repeatedly to set points for connected lines;
3. Hold the Alt key down to draw a stair-step (diagonal) line.

### Expected Result:
- The tool draws a stair-step (diagonal) line on the canvas.

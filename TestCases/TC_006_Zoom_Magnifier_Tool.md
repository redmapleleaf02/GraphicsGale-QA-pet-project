# GraphicsGale - Test Case 6

## ID: TC006
## Title: Using the "Zoom"/"Magnifier" tool

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Zoom"/"Magnifier" tool;
2. Left-click on canvas to zoom in;
3. Right-click on canvas to zoom out.

### Expected Result:
- The tool zooms in on the canvas when the user left-clicks;
- The tool zooms out on the canvas when the user right-clicks.

# GraphicsGale - Test Case 36

## ID: TC036
## Title: Using the "Spline Curve" tool. Canceling the last point

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Spline Curve" tool;
2. Left-click repeatedly to set points for curving lines;
3. Press the Esc key to cancel the last point.

### Expected Result:
- The Esc key cancels the last point.

# GraphicsGale - Test Case 32

## ID: TC032
## Title: Using the "Connect Line" tool. Canceling the last point

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Connect Line" tool;
2. Left-click repeatedly to set points for connected lines;
3. Press the Esc key to cancel the last point.

### Expected Result:
- The Esc key cancels the last point.

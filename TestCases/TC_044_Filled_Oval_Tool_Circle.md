# GraphicsGale - Test Case 44

## ID: TC044
## Title: Using the "Filled Oval" tool. Drawing a filled circle

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Filled Oval" tool;
2. Hold the Alt key down and drag to draw a filled circle.

### Expected Result:
- The tool draws a filled circle.

# GraphicsGale - Test Case 26

## ID: TC026
## Title: Using the "Color Selection" tool. Subtracting a selection area

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Color Selection" tool;
2. Left-click to create a selection area of similar color;
3. Hold the Alt key down and left-click to subtract an area from the current selection.

### Expected Result:
- The tool creates a selection area of similar color;
- When holding the Alt key down, the tool subtracts an area from the selection.

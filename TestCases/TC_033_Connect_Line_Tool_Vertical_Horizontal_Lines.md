# GraphicsGale - Test Case 33

## ID: TC033
## Title: Using the "Connect Line" tool. Drawing a vertical/horizontal line

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Connect Line" tool;
2. Left-click repeatedly to set points for connected lines;
3. Hold the Shift key down to draw a vertical or horizontal line.

### Expected Result:
- The tool draws a vertical or horizontal line on the canvas.

# GraphicsGale - Test Case 1

## ID: TC001
## Title: Making a new canvas

### Preconditions:
- User has an installed application;
- Application is accessible.

### Steps:
1. Open the application;
2. Use the "New" tool or press "Ctrl+N" hotkeys;
3. Set width, height and color mode;
4. Click the "OK" button.

### Expected Result:
- A new canvas is created with the specified width, height and color mode;
- The canvas is displayed in the workspace without errors.

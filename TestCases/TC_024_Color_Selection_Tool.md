## Title: Using the "Color Selection" tool

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Color Selection" tool;
2. Left-click to create a selection area of similar color.

### Expected Result:
- The tool creates a selection area of similar color.

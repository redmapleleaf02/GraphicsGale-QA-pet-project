# GraphicsGale - Test Case 38

## ID: TC038
## Title: Using the "Rectangle" tool. Drawing a hollow square 

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Rectangle" tool;
2. Hold the Alt key down and drag to draw a hollow square.

### Expected Result:
- The tool draws a hollow square.

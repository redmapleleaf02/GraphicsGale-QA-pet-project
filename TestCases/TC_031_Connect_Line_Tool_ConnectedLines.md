# GraphicsGale - Test Case 31

## ID: TC031
## Title: Using the "Connect Line" tool. Drawing connected lines

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Connect Line" tool;
2. Left-click repeatedly to set points for connected lines;
3. Right-click at the last point to finish drawing connected lines.

### Expected Result:
- The tool draws connected lines on the canvas.

# GraphicsGale - Test Case 4

## ID: TC004
## Title: Making a new canvas with negative values

### Preconditions:
- User has an installed application;
- Application is accessible.

### Steps:
1. Open the application;
2. Use the "New" tool or press "Ctrl+N" hotkeys;
3. Set any value with a minus sign for width, set any value with a minus sign for height and any color mode;
4. Click the "OK" button.

### Expected Result:
- A new canvas is created with the '1x1' size and with the specified color mode;
- The canvas is displayed in the workspace without errors.

# GraphicsGale - Test Case 35

## ID: TC035
## Title: Using the "Spline Curve" tool

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Spline Curve" tool;
2. Left-click repeatedly to set points for curving lines;
3. Right-click at the last point to finish drawing curving lines.

### Expected Result:
- The tool draws curving lines on the canvas.

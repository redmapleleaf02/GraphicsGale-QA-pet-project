# GraphicsGale - Test Case 29

## ID: TC029
## Title: Using the "Pen" tool. Drawing a stair-step (diagonal) line

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Pen" tool;
2. Hold the Alt key down and drag to draw a stair-step (diagonal) line on the canvas.

### Expected Result:
- The tool draws a stair-step (diagonal) line on the canvas.

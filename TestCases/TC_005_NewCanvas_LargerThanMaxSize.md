# GraphicsGale - Test Case 5

## ID: TC005
## Title: Making a new canvas larger than the maximum size

### Preconditions:
- User has an installed application;
- Application is accessible.

### Steps:
1. Open the application;
2. Use the "New" tool or press "Ctrl+N" hotkeys;
3. Set any value larger than '9999' for width, set any value larger than '9999' for height and any color mode;
4. Click the "OK" button.

### Expected Result:
- A new canvas is created with the '9999x9999' size and with the specified color mode;
- The canvas is displayed in the workspace without errors.

# GraphicsGale - Test Case 11

## ID: TC011
## Title: Using the "Rectangular Selection" tool. Subtracting a selection area

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Rectangular Selection" tool;
2. Left-click and drag to create a rectangular selection area on the canvas;
3. Hold the Alt key down and drag to subtract an area from the current selection.

### Expected Result:
- The tool creates a rectangular selection area on the canvas;
- When holding the Alt key down, the tool subtracts an area from the selection.

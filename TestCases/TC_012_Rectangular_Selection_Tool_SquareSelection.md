# GraphicsGale - Test Case 12

## ID: TC012
## Title: Using the "Rectangular Selection" tool. Making a square selection area

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Rectangular Selection" tool;
2. Hold the Alt key down, left-click and drag to create a square selection area on the canvas.

### Expected Result:
- The tool creates a square selection area on the canvas.

# GraphicsGale - Test Case 22

## ID: TC022
## Title: Using the "Magic Wand" tool. Adding an extra selection area

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Magic Wand" tool;
2. Left-click to create a selection area bounded by similar colors;
3. Hold the Shift key down and left-click to add an extra selection area.

### Expected Result:
- The tool creates a selection area bounded by similar colors;
- When holding the Shift key down, the tool adds an extra selection area.

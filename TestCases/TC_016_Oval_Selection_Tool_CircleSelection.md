# GraphicsGale - Test Case 16

## ID: TC016
## Title: Using the "Oval Selection" tool. Making a circle selection area

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Oval Selection" tool;
2. Hold the Alt key down, left-click and drag to create a circle selection area on the canvas.

### Expected Result:
- The tool creates a circle selection area on the canvas.

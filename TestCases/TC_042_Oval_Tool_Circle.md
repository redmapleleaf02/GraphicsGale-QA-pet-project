# GraphicsGale - Test Case 42

## ID: TC042
## Title: Using the "Oval" tool. Drawing a hollow circle

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Oval" tool;
2. Hold the Alt key down and drag to draw a hollow circle.

### Expected Result:
- The tool draws a hollow circle.

# GraphicsGale - Test Case 14

## ID: TC014
## Title: Using the "Oval Selection" tool. Adding an extra selection area

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Oval Selection" tool;
2. Left-click and drag to create an oval selection area on the canvas;
3. Hold the Shift key down and drag to add an extra selection area.

### Expected Result:
- The tool creates an oval selection area on the canvas;
- When holding the Shift key down, the tool adds an extra selection area.

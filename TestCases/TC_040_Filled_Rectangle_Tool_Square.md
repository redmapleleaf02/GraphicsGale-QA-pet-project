# GraphicsGale - Test Case 40

## ID: TC040
## Title: Using the "Filled Rectangle" tool. Drawing a filled square 

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Filled Rectangle" tool;
2. Hold the Alt key down and drag to draw a filled square.

### Expected Result:
- The tool draws a filled square.

# GraphicsGale - Test Case 27

## ID: TC027
## Title: Using the "Pen" tool

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Pen" tool;
2. Left-click and drag to draw on the canvas.

### Expected Result:
- The tool draws lines or strokes on the canvas following the cursor movement.

# GraphicsGale - Test Case 9

## ID: TC009
## Title: Using the "Rectangular Selection" tool

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Rectangular Selection" tool;
2. Left-click and drag to create a rectangular selection area on the canvas.

### Expected Result:
- The tool creates a rectangular selection area on the canvas.

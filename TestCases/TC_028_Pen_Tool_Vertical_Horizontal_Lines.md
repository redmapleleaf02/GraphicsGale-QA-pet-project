# GraphicsGale - Test Case 28

## ID: TC028
## Title: Using the "Pen" tool. Drawing a vertical/horizontal line

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Pen" tool;
2. Hold the Shift key down and drag to draw a vertical or horizontal line on the canvas.

### Expected Result:
- The tool draws a vertical or horizontal line on the canvas.

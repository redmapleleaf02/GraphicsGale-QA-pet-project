# GraphicsGale - Test Case 8

## ID: TC008
## Title: Using the "Mover" tool. Negative case

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas without the right and bottom scrollbars in the workspace.

### Steps:
1. Click on the "Mover" tool;
2. Click and drag the canvas.

### Expected Result:
- The tool does not move the canvas.

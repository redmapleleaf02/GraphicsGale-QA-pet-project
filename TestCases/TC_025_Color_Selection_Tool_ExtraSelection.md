# GraphicsGale - Test Case 25

## ID: TC025
## Title: Using the "Color Selection" tool. Adding an extra selection area

### Preconditions:
- User has an installed application;
- Application is accessible;
- User has an opened canvas in the workspace.

### Steps:
1. Click on the "Color Selection" tool;
2. Left-click to create a selection area of similar color;
3. Hold the Shift key down and left-click to add an extra selection area.

### Expected Result:
- The tool creates a selection area of similar color;
- When holding the Shift key down, the tool adds an extra selection area.
